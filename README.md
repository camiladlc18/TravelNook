# 🌍 Travel Nook

**Travel Nook** es una página web sencilla diseñada para inspirar a los usuarios a explorar destinos increíbles alrededor del mundo. La aplicación permite buscar entre una lista de países y ciudades destacadas, mostrando información esencial de cada lugar.

Prueba la página con el siguiente enlace:

https://camiladlc18.github.io/TravelNook/

## 🛠 Características

- **Explora destinos populares**: Descubre lugares icónicos de diferentes países como Australia, Japón y Brasil.
- **Búsqueda rápida**: Encuentra destinos por nombre con la funcionalidad de búsqueda.
- **Información clave**: Cada lugar incluye una descripción breve, imágenes atractivas y un botón de acceso para reservar directamente en Booking.com.

## 🔎 ¿Qué puedes buscar?
Para utilizar la barra de búsqueda, puedes ingresar los siguientes términos:  

- Nombres de países:  
  - `Australia`  
  - `Japan`  
  - `Brazil`  

- Palabras clave específicas:  
  - `temples`  
  - `beaches` 

## ✨ Objetivo
El propósito de Travel Nook es animar a los usuarios a conocer nuevos destinos, destacando las maravillas culturales, históricas y naturales de diferentes lugares.

## 🖼 Vista previa
> La página cuenta con un diseño limpio y una interfaz fácil de usar, perfecta para viajeros que buscan inspiración para su próxima aventura.
